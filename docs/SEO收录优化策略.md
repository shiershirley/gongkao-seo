## 二、未收录原因分析

### 1. 正常情况（无需担心）
- **文章太新**：仅发布1天，爬虫抓取有延迟
  - 百度：通常1-7天
  - Google：通常1-3天
  - Bing：通常1-5天

### 2. 需要优化的点
- **未主动提交URL**：sitemap虽已声明，但未主动向搜索引擎提交
- **缺少外部链接**：新站缺乏外部链接导入权重
- **内容相似度**：与已收录文章可能存在内容重复

---

## 三、优化方案

### 方案1：主动提交sitemap（推荐）

将sitemap提交至搜索引擎：

**百度搜索资源平台**：
1. 访问 https://ziyuan.baidu.com
2. 登录 → 验证网站所有权
3. 提交sitemap: `https://gk.edu-sjtu.cn/sitemap.xml`

**Google Search Console**：
1. 访问 https://search.google.com/search-console
2. 添加网站 → 验证所有权
3. 提交sitemap: `https://gk.edu-sjtu.cn/sitemap.xml`

### 方案2：自动化URL提交（进阶）

在文章生成后，自动向搜索引擎API提交URL：

**百度主动推送API**：
```bash
curl -H 'Content-Type:text/plain' \
--data-binary @urls.txt \
"http://data.zz.baidu.com/urls?site=gk.edu-sjtu.cn&token=YOUR_TOKEN"
```

### 方案3：增加外链建设

1. **社交媒体分发**：在知乎、微信公众号等平台发布摘要并链接到原文
2. **论坛/社区推广**：在豆瓣、贴吧等社区分享有价值内容
3. **书签网站**：在百度收藏、QQ书签等平台收藏

### 方案4：文章内容优化

**关键词密度优化**：
- 确保核心关键词在title、h1、description中自然出现
- 关键词密度建议：2%-5%

**文章结构优化**：
- 使用H2/H3标题层级
- 添加表格、列表等结构化内容
- 确保文章长度≥1500字

**内链优化**：
- 新文章添加指向旧文章的链接
- 旧文章更新时添加指向新文章的链接

## 四、执行建议

```

         ↓
    sitemap自动更新（Vercel钩子）
         ↓
    收录检查（次日）
         ↓
    如未收录 → 主动提交URL
```

### 收录监控频率

- **每日检查**：使用脚本检查前一天文章收录状态
- **每周汇总**：统计整体收录率，调整策略
- **每月复盘**：分析收录数据，优化内容方向
