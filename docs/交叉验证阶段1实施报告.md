## 六、附录：验证脚本完整参数说明

### frontmatter_validator.py
```
positional arguments:
  paths                 要检查的文件或目录路径（默认：content目录）

options:
  -h, --help            show this help message and exit
  --fix                 自动修复可识别的问题
  --content-check       启用正文内容质量检查（字数、关键词密度等）
  --check-keyword CHECK_KEYWORD
                        检查单篇文章是否覆盖指定关键词
```

### cross_validate_batch.py
```
positional arguments:
  paths                 要检查的文件或目录路径（默认：content目录）

options:
  -h, --help            show this help message and exit
  --date DATE           检查指定日期的文章（格式：YYYY-MM-DD）
  --title-threshold TITLE_THRESHOLD
                        标题相似度阈值（默认：0.6）
  --content-threshold CONTENT_THRESHOLD
                        内容相似度阈值（默认：0.3）
  --keyword-threshold KEYWORD_THRESHOLD
                        关键词重叠阈值（默认：3）
  --output OUTPUT       输出文件路径
  --format {text,json} 输出格式（默认：text）
```
