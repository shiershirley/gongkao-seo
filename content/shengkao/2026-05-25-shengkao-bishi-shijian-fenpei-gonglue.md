# 省考笔试时间分配攻略：90分钟考出最高分的策略

省考笔试有一个残酷的现实：题目太多，时间太少。

行测120分钟100-130道题，申论180分钟3-4道大题。稍不注意，就会出现「后面还有20道题没做」的悲剧。

本文专项解决时间分配问题，帮你用同样的时间拿到更高的分。

![备考资料](/images/lib/books/books_v18_003.jpg)

## 一、行测时间分配总体策略

### 全局时间规划（以120分钟为例）

| 模块 | 建议用时 | 题目数量 | 每题用时 |
|------|---------|---------|---------|
| 言语理解 | 25-30分钟 | 40题 | 40-45秒 |
| 数量关系 | 15-20分钟 | 10-15题 | 60-90秒 |
| 判断推理 | 30-35分钟 | 35-40题 | 50-60秒 |
| 资料分析 | 20-25分钟 | 15-20题 | 60-90秒 |
| 常识判断 | 10-15分钟 | 20-25题 | 30秒 |
| 检查涂卡 | 5-10分钟 | — | — |

**核心原则：** 不是每道题都要认真做，而是每道题都要填答案。

### 行测做题顺序建议

很多考生按照题目顺序从头做到尾，这是时间管理的大忌。

**推荐顺序：**

1. **资料分析**（先做）：题型稳定，性价比高，做完有成就感
2. **言语理解**：数量多但每题用时短，能快速积累分数
3. **判断推理**：图形推理可以快速做，逻辑判断选选取
4. **常识判断**：纯靠积累，不会的果断猜
5. **数量关系**（最后或跳过难题）：难题耗时长，不要在这里浪费时间

### 各模块详细策略

**言语理解（40题/25分钟）**

- 逻辑填空：每题30秒，靠语感为主，不要过度分析
- 阅读理解：每篇文章不超过4分钟（含做题）
- 标记难题：感觉超过40秒还不确定的，先跳过，后面回来

**数量关系（15题/20分钟）**

- 先做看一眼就有思路的题目
- 计算量超过3步的题目，立即放弃
- 目标是做对7-10道，放弃5道也没关系

**判断推理（40题/35分钟）**

- 图形推理：每题20-30秒，有思路就做，没思路立即猜
- 定义判断：每题40秒，关键词匹配法
- 类比推理：每题20秒，最快的题型
- 逻辑判断：每题50-60秒，真假话题和论证题要慎重

**资料分析（20题/25分钟）**

- 先浏览一遍材料（3分钟），建立整体概念
- 每道题60-90秒，计算量大的先估算，选项差异大可以用近似值

**常识判断（25题/15分钟）**

- 每题30秒，有把握就选，没把握就猜B或C（经验值）
- 不要在常识题上死磕，这是最无法临时提升的模块

## 二、申论时间分配策略

### 全局时间规划（180分钟为例）

| 题目类型 | 建议用时 | 备注 |
|---------|---------|------|
| 阅读材料 | 25-30分钟 | 边读边标注关键词 |
| 归纳概括题（小题） | 15-20分钟/道 | 快速定位材料要点 |
| 对策建议题 | 15-20分钟/道 | — |
| 综合分析题 | 20-25分钟/道 | — |
| 大作文 | 55-65分钟 | 含构思15分钟 |
| 检查修改 | 5-10分钟 | — |

**关键原则：** 大作文是申论得分的「重中之重」，必须留足时间。

### 申论阅读技巧（节省10分钟）

很多考生阅读材料耗时过长，是因为阅读方式不对。

**高效阅读法：**

1. **先看题目**（3分钟）：了解考什么，带着问题读材料
2. **速读材料**（20分钟）：重点关注：
   - 每段首句（通常是核心观点）
   - 数据和举例（可跳过细节）
   - 转折句（「但是」「然而」后面的内容）
3. **标注要点**：用铅笔标出答题材料的出处段落

**不同题型需要关注的材料类型：**
- 归纳概括题：关注问题/现象/做法
- 对策题：关注原因和已有经验
- 大作文：关注核心议题和论点支撑

### 大作文时间管理（65分钟完成）

大作文是申论得分的关键，以下是65分钟内完成高质量大作文的时间分配：

| 阶段 | 用时 | 核心任务 |
|------|------|---------|
| 审题 | 3分钟 | 确定主题、立意方向 |
| 构思提纲 | 10分钟 | 想好论点、选好素材 |
| 写引言（150字） | 8分钟 | 背景+问题+中心论点 |
| 写分论点1（300字） | 12分钟 | 论点句+论据+总结 |
| 写分论点2（300字） | 12分钟 | 同上 |
| 写分论点3（200字） | 8分钟 | 同上（可稍短） |
| 写结论（150字） | 8分钟 | 总结+升华 |
| 检查 | 4分钟 | 错别字、标点、字数 |

**提速技巧：**
- 字迹不用追求漂亮，但要清晰
- 用铅笔先写提纲再用笔写正文（节省反复修改时间）
- 论据优先使用材料中的内容，不需要额外编造

## 三、考场紧急时间救援方案

### 情况1：发现还有20道行测题没做（剩余时间<20分钟）

**立即执行：**
1. 停止做当前题目（即使做了一半）
2. 快速翻到最后，确认未做题目数量
3. 每道题只用10-15秒，选「最像的」答案
4. 所有未做题目全部填同一个选项（如B），概率上能保底

### 情况2：申论大作文还剩30分钟但才写了开头

**立即执行：**
1. 不要追求质量，保证完成度
2. 写出框架：标题 + 开头段（3句话） + 3个分论点标题句 + 3个简短论证 + 结尾段
3. 字数不够可以在每个段落后补充1-2句总结句
4. 宁可言简意赅，不能空白

### 情况3：申论小题做超时，大作文时间不够

**立即执行：**
1. 快速结束当前小题（哪怕不完整），留出大作文时间
2. 大作文扣分比小题不完整扣分影响更大
3. 原则：大作文时间必须保证55分钟以上

## 四、备考阶段的时间管理训练

### 模拟考试的重要性

很多考生备考时只做练习题，从不进行全真模拟。这是造成考场时间失控的主要原因。

**建议：**
- 考前至少进行3次全真模拟（行测120分钟不中断，申论180分钟不中断）
- 每次模拟后统计各模块用时，找出时间漏洞
- 专项训练超时的模块

### 速度与准确率的平衡

行测有一个规律：**速度提升到一定程度后，准确率会下降**。

建议的准确率底线：
- 言语理解：75%以上（做得快也要保证质量）
- 判断推理：70%以上
- 资料分析：75%以上（计算题准确率很重要）
- 数量关系：60%以上（会的做对，不会的别浪费时间）

## 总结

省考笔试时间管理的核心思维：

1. **全局优先**：先规划整体时间，再进入每道题
2. **舍弃策略**：有意识地放弃性价比低的题目
3. **保底策略**：每道题必须填答案，哪怕是猜的
4. **大作文优先**：申论时间管理的首要原则是保护大作文时间

考场不是比谁最努力，而是比谁最聪明地分配时间。合理的时间管理，往往比多背几道题更有价值。
