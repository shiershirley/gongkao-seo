在省考申论中，大作文固然重要，但真正决定申论分数的往往是前三道小题。这三道题通常合计占60-70分，而大作文只占30-40分。然而遗憾的是，绝大多数考生把备考精力的80%花在了大作文上，对小题却掉以轻心。本文带你重新认识申论小题，掌握科学高效的答题方法。

## 一、申论小题命题规律

各省申论小题虽然具体题目不同，但题型基本稳定在三类：

| 题型 | 考查能力 | 分值（约） | 常见问法 |
|------|---------|-----------|---------|
| 归纳概括 | 阅读理解、提炼要点 | 15-25分 | 「概括……」「归纳……」 |
| 提出对策 | 解决问题 | 20-25分 | 「提出对策」「建议措施」 |
| 综合分析 | 全面分析、逻辑表达 | 20-30分 | 「分析……」「谈谈看法」 |

## 二、归纳概括题答题方法

### 命题特点

归纳概括题是申论小题中最基础的题型，考查从给定材料中提取关键信息的能力。问法通常为「根据给定资料X，概括/归纳……」

### 三步答题法

**第一步：审题定范围**

拿到题目后先用笔圈出四个要素：
- 概括对象：是"问题""原因""影响"还是"做法"？
- 材料范围：题目指定了哪几则材料？
- 字数限制：不超过多少字？
- 是否有特殊要求：如"条理清晰""分类合理"？

**第二步：材料标要点**

逐段阅读指定材料，用笔标注要点。标准格式：
```
P1-①：问题表现（……）
P1-②：直接原因（……）
P2-①：间接影响（……）
```

这样可以避免遗漏要点，也便于后续分类整理。

**第三步：分类写答案**

将标注的要点按逻辑进行归类。分类角度包括：
- 按主体：政府层面、企业层面、个人层面
- 按领域：制度层面、资金层面、人才层面、技术层面
- 按逻辑：问题→原因→影响，或者表层→深层

**答案格式示例**：
```
一、制度层面：1.……2.……
二、执行层面：1.……2.……
三、监督层面：1.……2.……
```

### 常见失分点

| 失分原因 | 纠正方法 |
|---------|---------|
| 要点遗漏 | 先用铅笔在材料上标记，再逐条整理 |
| 照抄原文 | 提炼核心意思，用自己的话转述 |
| 没有分类 | 写完要点后花1分钟分组归类 |
| 超字数 | 合并同类项，删除修饰性词语 |
| 逻辑混乱 | 先列提纲再写正式答案 |

## 三、提出对策题答题方法

### 命题特点

提出对策题要求针对材料中反映的问题，提出切实可行的解决方案。问法一般为「针对……问题，提出对策建议」或「请就……提出解决办法」。

### 对策来源

| 来源 | 说明 | 示例 |
|------|------|------|
| 材料直接给出 | 材料中明确提到解决措施 | "加强监管""完善制度" |
| 问题反向推导 | 有问题就有对策方向 | 问题"设备老化"→对策"更新设备" |
| 经验借鉴 | 材料中其他地区的成功做法 | "某市推行XX机制"→可推广 |
| 主体分析法 | 从不同主体角度思考 | 政府做什么、企业做什么、个人做什么 |

### 对策题万能框架

**制度机制类对策**
- 建立健全……制度体系
- 完善……工作机制
- 制定……实施细则/管理办法

**监督管理类对策**
- 加强日常监督检查
- 建立考核评价机制
- 畅通群众投诉举报渠道

**资源保障类对策**
- 加大财政资金投入
- 加强专业人才队伍建设
- 推进信息化平台建设

**宣传教育类对策**
- 加强政策宣传解读
- 开展专题培训教育
- 树立先进典型示范

### 常见误区

1. **对策太空泛**：如"加强管理"太笼统，应具体到"建立定期巡检制度，每月至少检查一次"
2. **对策不可行**：提出的方案在现有条件下无法实施
3. **对策与问题不对应**：提出的对策不能解决材料中的问题
4. **对策堆砌不分主次**：应先说最核心的对策，再补充配套措施

## 四、综合分析题答题方法

### 命题特点

综合分析题是申论小题中难度最高的题型，要求对某一观点、现象或句子进行全面深入的分析。常见问法：「请对……进行评析」「谈谈你对……的理解」。

### 四步分析法

**第一步：表态**（是什么）

先用一句话亮明你的基本判断：
- 这句话是正确的/片面的/需要辩证看待的
- 这个现象是积极的/消极的/复杂的

**第二步：分析理由**（为什么）

从2-3个角度展开论证：
- 从材料中找支撑论据
- 从现实逻辑中推理
- 从政策理论中论证

**第三步：指出问题**（怎么看局限）

如果是正面观点，指出实施中可能的困难
如果是负面观点，分析其产生的原因
如果是中性观点，剖析其两面性

**第四步：提出建议**（怎么办）

基于分析给出建设性意见，不求多但求精

### 答案框架模板

```
该观点/现象具有一定的合理性/需要辩证看待。

一方面，……（正面分析，1-2个要点）。
另一方面，……（指出问题或局限性，1-2个要点）。

因此，我们应当……（提出1-2条针对性建议）。
```

## 五、各题型时间分配建议

以150分钟的申论考试为例：

| 环节 | 题型 | 建议时间 | 说明 |
|------|------|---------|------|
| 审题 | 全部 | 5分钟 | 通读所有题目，规划答题顺序 |
| 阅读 | 全部材料 | 30-35分钟 | 带着问题读材料，边读边标注 |
| 小题一 | 归纳概括 | 25-30分钟 | 审题3分钟+找要点10分钟+写作12分钟 |
| 小题二 | 提出对策 | 25-30分钟 | 审题3分钟+思考对策10分钟+写作12分钟 |
| 小题三 | 综合分析 | 30-35分钟 | 审题3分钟+深入理解12分钟+写作15分钟 |
| 大作文 | 议论文 | 40-45分钟 | 审题5分钟+列提纲5分钟+写作30分钟+检查5分钟 |

## 六、日常训练方法

### 每日训练计划

| 阶段 | 训练内容 | 题量 |
|------|---------|------|
| 基础期 | 单题型专项训练 | 每天1道小题 |
| 提升期 | 混合题型训练 | 每天2道小题 |
| 冲刺期 | 完整模拟训练 | 每2天1套完整申论卷 |

### 复盘方法

做完题不等于练到位，真正提升在于复盘：
1. 对照参考答案，逐条比对得分点
2. 标记遗漏的要点，分析遗漏原因
3. 学习参考答案的表述方式和分类逻辑
4. 将优质表述积累到自己的"申论语料库"
