# 省考行测数量关系高频题型速解技巧：工程问题+行程问题+利润问题

![职场工作](/images/lib/office/o4_4.jpg)

「数量关系好难，每次都做不完，干脆全选C算了」——这是很多省考考生的真实心声。行测考试中，数量关系通常10—15道题，题目本身确实有难度，但更要命的是**时间不够**。120分钟要完成120—135道题，平均每题不到1分钟，数量关系往往被挤压到最后只剩「蒙题时间」。

但其实，数量关系中有相当一部分题型是**有速解方法的**，掌握这些方法，不需要太深的数学功底也能拿到一半以上的分数。本文聚焦三大高频题型，只讲考场上真正用得上的速解技巧。

## 一、数量关系考场的三条铁律

在讲具体技巧之前，先明确考场策略：

| 策略 | 具体做法 |
|------|---------|
| **先挑软的吃** | 浏览全部数量关系题，先做自己最擅长的类型 |
| **1分钟原则** | 每题最多花1分钟，超时立即跳下一题 |
| **不空题** | 做不完的统一选同一个选项（如全选B或C） |

![考试上岸](/images/lib/exam/exam_paper.jpg)

记住：数量关系的目标不是全对，而是**在有限时间内拿到能力范围内的最高分**。

## 二、工程问题——赋值法一键秒杀

### 题型识别
题干涉及「完成一项工程」「修一条路」「加工一批零件」等，有工作总量、工作效率和完成时间三类量。

### 速解技巧：赋值总量法

当题目给出多个主体的工作时间，但没给具体工作量时，直接把工作总量赋值为各时间的**公倍数**。

### 口诀
> 多个时间求合作，总量赋值为公倍数。

### 真题示例

> 一项工程，甲单独做需要12天完成，乙单独做需要18天完成。两人合作需要多少天？

**速解步骤**：
1. 赋总量：12和18的最小公倍数是36，所以工作总量 = 36
2. 算效率：甲效率 = 36÷12 = 3，乙效率 = 36÷18 = 2
3. 合作效率 = 3+2 = 5
4. 合作时间 = 36÷5 = 7.2天

20秒出答案，完全不需要设未知数。

### 进阶变式：交替合作

> 甲单独做需12天，乙单独做需18天。按甲一天、乙一天的顺序交替工作，需要多少天？

**思路**：赋总量为36，每2天（甲+乙各1天）完成5，36÷5=7周期余1，7周期=14天，余下的1由甲第15天做（甲效率3，1÷3=1/3天），所以总共14又1/3天。

## 三、行程问题——比例法快速推理

### 题型识别
题干涉及路程、速度、时间三者，通常有相遇、追及、往返等场景。

### 速解技巧：比例法

在行程问题中，当路程一定时，速度和时间成反比；当时间一定时，路程和速度成正比。

不需要列复杂方程，用比例关系心算即可。

### 真题示例

> 某人以每小时5公里的速度从A地走到B地，回来时速度提高到每小时6公里。往返共用了5.5小时，A、B两地相距多少公里？

**速解步骤**：
1. 路程相同，速度比 5:6，时间比 = 6:5（反比）
2. 去程占6份时间，回程占5份时间，共11份
3. 11份 = 5.5小时 → 1份 = 0.5小时
4. 去程时间 = 6×0.5 = 3小时
5. 路程 = 5×3 = 15公里

全程纯比例推理，不需要列方程。

### 进阶：相对运动

> 两列火车相向而行，分别长200米和300米，速度分别为20m/s和15m/s。从车头相遇到车尾分离需要多长时间？

**思路**：
- 相对速度 = 20+15 = 35m/s（相向）
- 需要经过的总距离 = 200+300 = 500米
- 时间 = 500÷35 ≈ 14.3秒

## 四、利润问题——公式代入法

### 题型识别
题干涉及「进价」「售价」「利润」「折扣」「利润率」等商业词汇。

### 核心公式表

| 公式 | 应用场景 |
|------|---------|
| 利润 = 售价 — 进价 | 基础计算 |
| 利润率 = 利润÷进价×100% | 涉及「百分之多少的利润」 |
| 折扣后售价 = 原价×折扣 | 打折场景 |
| 售价 = 进价×(1+利润率) | 定价策略 |

### 速解技巧

利润问题最常见的速解方式是**赋值进价为100**——把所有成本类的数据设为100，后续计算直接心算。

### 真题示例

> 某商品按20%的利润定价，然后按8.8折出售，获得利润84元。该商品的进价是多少？

**速解步骤**：
1. 设进价为100（赋值法）
2. 定价 = 100×(1+20%) = 120
3. 8.8折售价 = 120×0.88 = 105.6
4. 当进价为100时利润 = 5.6
5. 实际利润84是5.6的15倍 → 实际进价 = 100×15 = 1500元

验证：进价1500，定价1800，8.8折售价1584，利润84，正确。

## 五、数量关系的「保底」技巧

### 技巧一：代入验证法
当列方程费时或不确定时，直接从选项入手。将选项代入题干验证，快速排除。

适用题型：年龄问题、不定方程、多位数问题

### 技巧二：整除特性法
利用数的整除性质快速排除选项。比如「若干人分若干物品，每人分a个还剩b个」，总人数必定是总物品数减去b后除以a的整数。

### 技巧三：选项猜题法（最后的底牌）
真的一道都不会的时候：
- 如果题目出现「最多/最少」，答案往往在中间值附近
- 如果题目涉及比例，优先验证能被比例分母整除的选项
- 如果是计算类题目，优先验证「整」一点的结果
