# 省考申论归纳概括题高分答题方法

归纳概括题是省考申论中最基础、出现频率最高的题型，几乎逢考必出。它看似简单，但要拿到高分并不容易——很多考生能找到要点，却因为归纳能力不足、答题逻辑混乱而失分。本文将从审题、找点、归纳、作答四个环节，系统讲解归纳概括题的高分答题方法。

## 一、归纳概括题的题型认知

### 常见出题形式

归纳概括题的设问方式通常为：
- 「概括/归纳......的原因/问题/做法/表现/影响/变化」
- 「根据材料X，总结/梳理......」
- 「请分析材料中......的主要特点」

![](/images/lib/books/books_v24_118.jpg)

### 题型特点

1. **客观性强**：答案基本来自给定材料，不需要考生主观发挥
2. **分值占比高**：通常10-15分，有时会出现两道归纳概括题
3. **字数限制严格**：一般要求100-300字，对语言精炼度要求高
4. **要点分散**：关键信息可能分布在一篇或多篇材料中

## 二、审题：精准把握作答方向

审题是答题的第一步，也是最容易出错的一步。审题要做到「四个明确」：

### 1. 明确概括对象

搞清楚题目要求概括的是什么——是问题、原因、做法、影响还是变化？不同的概括对象决定了阅读材料时的关注重点。

| 概括对象 | 关注重点 | 关键提示词 |
|---------|---------|-----------|
| 问题 | 不好的现象、存在的不足 | 困难、挑战、瓶颈、缺失、滞后 |
| 原因 | 导致问题产生的因素 | 由于、因为、根源在于、与...有关 |
| 做法 | 采取的措施、方法、经验 | 通过、实施、推行、建立了、开展了 |
| 影响 | 产生的结果、效果 | 促进了、推动了、导致了、改善了 |
| 变化 | 从前到后的转变 | 从...到...、转变、升级、改善 |

### 2. 明确材料范围

题目通常会指定「根据/依据材料X」，必须严格在指定范围内找点，不要超出范围。

### 3. 明确作答要求

常见要求包括：
- 「全面」：要点不能遗漏
- 「准确」：用词精准，不能曲解材料原意
- «条理清楚»：分条作答，逻辑清晰
- 「不超过X字」：严格控制字数

### 4. 明确特殊限制

注意是否有「分类合理」「分条归纳」等特殊要求，这决定了答案的组织方式。

## 三、找点：高效提取关键信息

找点是归纳概括题的核心环节，掌握正确的阅读方法可以大幅提高找点效率。

### 1. 关键词定位法

在阅读材料时，重点关注以下关键词：

**转折词**：但是、然而、可是、却——转折词后面通常是重要信息
**总结词**：总之、因此、可见、综上——总结词后面往往是核心观点
**强调词**：特别是、尤其是、更重要的是、关键在于——强调词后面是重点
**并列词**：一方面、另一方面、同时、此外、另外——并列词帮助发现多个要点

### 2. 段落结构分析法

根据段落的组织结构，快速定位要点所在位置：

- **总分结构**：首句或尾句通常是总括句
- **并列结构**：每个并列段落各包含一个要点
- **递进结构**：各要点存在层次递进关系
- **对比结构**：对比双方各自的特点都是潜在要点

### 3. 要点标注技巧

在材料上直接标注要点，使用统一标记：
- 用「○」圈出核心词
- 用「——」划出支撑句
- 用数字「1、2、3」标注要点序号

## 四、归纳：提炼与合并的艺术

找到要点之后，最关键的一步是归纳。归纳概括题之所以难，就在于不仅要找到要点，还要对要点进行合理的提炼和合并。

### 1. 同义合并法

将表达相同或相近意思的要点合并为一个：

**示例**：
- 原始要点：A社区设立了居民议事厅；B社区组建了居民协商会；C社区定期召开居民代表大会
- 归纳后：搭建居民参与平台（设立议事厅、组建协商会、召开代表大会）

### 2. 上位概念法

用更高层次的概念涵盖多个具体要点：

![](/images/lib/books/books_v24_116.jpg)

**示例**：
- 原始要点：修建了文化广场；建设了图书室；开设了健身中心；打造了老年活动室
- 归纳后：完善文化设施建设

### 3. 逻辑分类法

按照一定的逻辑对要点进行分类组织：

**常用分类框架**：
- **按维度分类**：思想层面、制度层面、执行层面
- **按主体分类**：政府、企业、社会、个人
- **按时间分类**：事前、事中、事后
- **按要素分类**：人、财、物、制度、技术

## 五、作答：规范书写高分答案

### 答案结构

归纳概括题的答案建议采用「总括句 + 分条要点」的结构：

```
总括句（高度概括，点明核心）
1. 要点一（核心词 + 具体展开）
2. 要点二（核心词 + 具体展开）
3. 要点三（核心词 + 具体展开）
```

### 书写规范

1. **核心词前置**：每条要点的开头用精炼的核心词概括
2. **标点规范**：序号后用顿号或点号，要点之间用分号
3. **字数控制**：总括句10-20字，每个要点30-50字
4. **卷面整洁**：书写工整，避免涂改

### 高分答案示例

**题目**：请根据材料，概括当前基层治理中存在的问题。（15分，200字以内）

**高分答案**：

当前基层治理存在以下问题：一是权责不匹配，基层承担大量行政事务但缺乏相应权限和资源；二是人才匮乏，基层工作人员数量不足、专业能力有待提升；三是群众参与度低，居民对社区事务关注度不高，参与渠道有限；四是信息化水平不高，数据共享机制不完善，存在重复录入和「信息孤岛」现象。

## 六、常见失分原因及规避

1. **要点遗漏**：材料中明显存在的要点没有写到——需仔细阅读，不跳读
2. **归纳不够**：直接抄写原文，没有进行提炼——需练习同义合并和上位概念
3. **逻辑混乱**：要点之间没有明确分类——需先分类再作答
4. **字数超标**：归纳不够精炼——需严格控制每个要点的字数
5. **答非所问**：概括对象搞混——需认真审题，明确概括方向

归纳概括题看似简单，实则是申论高分的基础。建议考生在备考过程中，每天至少练习2道归纳概括题，重点训练找点的速度和归纳的精准度，逐步培养「读完即能概括」的能力。
