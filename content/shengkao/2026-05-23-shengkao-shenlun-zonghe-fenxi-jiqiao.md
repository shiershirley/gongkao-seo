省考申论考试中，综合分析题是很多考生的「失分重灾区」。这类题目要求考生对给定资料中的某个词句、观点或现象进行深入分析，不仅考察阅读理解能力，更考察逻辑思维和分析能力。

## 一、综合分析题题型分类

### 类型一：词句分析题

**提问方式**：
- 请你谈谈对「……」这句话的理解。
- 给定资料4中提到「……」，请结合资料谈谈你的理解。

**答题重点**：解释句子含义 + 分析理由 + 总结提升

### 类型二：观点分析题

**提问方式**：
- 资料中出现了两种不同观点，请你对此进行分析。
- 有人认为……，有人认为……，你怎么看？

**答题重点**：点明争议焦点 + 分别分析 + 提出自己的看法

### 类型三：现象分析题

**提问方式**：
- 给定资料反映了……现象，请你对此进行分析。
- 请你对……现象产生的原因及影响进行分析。

**答题重点**：点明现象 + 分析原因/影响 + 提出对策

## 二、综合分析题通用答题框架

### 「是什么─为什么─怎么办」三步法

**第一步：是什么（解释/点明）**

用1-2句话解释句子含义，或点明观点/现象的本质。

**示例**：
```
「绿水青山就是金山银山」这句话，深刻揭示了生态环境保护
与经济发展之间的辩证统一关系，指出良好生态本身就能
产生经济效益。
```

**第二步：为什么（分析）**

这是答题的核心部分，要从多角度展开分析：

- **分析原因**：为什么会出现这种现象？
- **分析影响**：这种现象带来了哪些正面/负面影响？
- **分析现状**：当前在这方面存在哪些问题？

**第三步：怎么办（总结/对策）**

提出解决问题的对策，或总结升华主题。

**示例**：
```
因此，在推进高质量发展过程中，必须坚持生态优先、绿色发展，
使绿水青山产生巨大的生态效益、经济效益、社会效益。
```

## 三、各类综合分析题详细答题技巧

### 词句分析题答题技巧

**技巧一：拆分句子关键词**

将句子中的关键词逐一解释，再串联成文。

**示例**：句子「乡村振兴，人才是关键」
- 乡村振兴：战略目标
- 人才：第一资源
- 关键：核心要素
- 串联：乡村振兴需要人才支撑……

**技巧二：从「释义─原因─影响─对策」展开**

```
释义：「……」这句话的意思是……
原因：之所以……，是因为……
影响：这样做有利于……；反之则会……
对策：因此，我们要……
```

### 观点分析题答题技巧

**技巧一：先概括争议焦点**

不要直接跳入分析，先一句话点明双方在争论什么。

**示例**：
```
材料中的两种观点，实质上是在争论「……」。
一种观点认为……；另一种观点认为……。
```

**技巧二：辩证分析，不偏废**

如果两种观点都有道理，采用「A有道理，但B也不可忽视」的辩证表述。

### 现象分析题答题技巧

**技巧一：先点明现象本质**

```
……现象的出现，反映出……
```

**技巧二：多角度分析原因**

- 个人层面
- 社会层面
- 制度层面
- 文化层面

**技巧三：分析影响要分正负**

```
……现象既有积极意义，也存在一些问题。
积极方面：……
问题方面：……
```

## 四、综合分析题评分标准

| 评分维度 | 分值占比 | 高分特征 |
|----------|----------|----------|
| 分析深度 | 40% | 能透过现象看本质，分析有层次 |
| 逻辑结构 | 30% | 条理清晰，层次分明 |
| 资料结合 | 20% | 紧密围绕给定资料，不脱离 |
| 语言表达 | 10% | 通顺流畅，无语病 |

**扣分点**：
- 脱离给定资料，空谈理论（扣3-5分）
- 逻辑混乱，层次不清（扣3-5分）
- 分析浮于表面，没有深度（扣2-4分）
- 字数严重不足，少于150字（扣3-5分）

## 五、综合分析题高分实战示例

**题目**：给定资料中提到「数字鸿沟成为老年人融入智慧社会的绊脚石」，请谈谈你对这句话的理解。（20分）

**参考答案框架**：

```
「数字鸿沟成为老年人融入智慧社会的绊脚石」这句话，
深刻指出了当前数字化进程中，老年群体面临的技术使用障碍
问题。[释义]

随着数字技术快速普及，网上办事、手机支付、线上挂号等
成为生活常态。但不少老年人不会使用智能手机，无法享受
数字化便利，甚至在就医、出行等场景遭遇障碍。[点明现象]

造成数字鸿沟的原因是多方面的。从技术层面看，很多APP
界面复杂、字体小，没有适老化改造；从社会层面看，
家庭和社会对老年人数字技能培训不足；从老年人自身看，
年龄增长导致学习能力下降，对新技术有畏难情绪。[分析原因]

数字鸿沟不仅影响老年人生活质量，也违背了智慧社会建设
「一个都不能少」的初衷。帮助老年人跨越数字鸿沟，是
社会治理精细化的重要体现。[分析影响]

因此，应从三方面着手：一是推进互联网应用适老化改造；
二是开展老年人数字技能培训；三是保留必要的线下服务渠道，
不让任何一个群体被数字时代落下。[提出对策]
```

## 六、省考申论综合分析题备考建议

### 建议一：精读人民日报评论员文章

每天阅读1-2篇人民日报评论员文章，分析其论证结构，积累分析问题的角度和表达方式。

### 建议二：分题型专项训练

将综合分析题分为词句分析、观点分析、现象分析三类，每类练习5-10题，形成稳定答题框架。

### 建议三：对照答案反思差距

每次练习后，对照标准答案找出自己的差距：是分析深度不够？还是逻辑结构不清？针对性改进。

省考申论综合分析题高分的秘诀在于「框架稳定 + 分析深入 + 语言规范」。建议考生熟记本文介绍的答题框架，并通过反复练习形成肌肉记忆，在考场上从容应对各类综合分析题目。
