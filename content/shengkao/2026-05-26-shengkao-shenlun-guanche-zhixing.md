## 省考申论贯彻执行题解题方法与高分模板

在省考申论的各类题型中，贯彻执行题（也称公文写作题）的分值占比高、考查频次稳定，是申论拿高分的「必争之地」。![](/images/lib/exam/ep3_1.jpg)

然而，许多考生对这类题型存在畏难情绪，究其原因，往往是对公文格式不熟悉、对材料运用不到位。本文将从解题方法和模板技巧两个维度，为您系统拆解贯彻执行题。

### 一、贯彻执行题的命题特点

贯彻执行题要求考生根据给定材料和题目要求，撰写一份具有实务操作性的工作文书。常见的文种包括：

- **讲话稿类**：开幕词、闭幕词、经验交流发言稿、动员讲话
- **方案计划类**：工作方案、实施计划、整改方案
- **报告类**：调研报告、情况汇报、工作总结
- **宣传类**：倡议书、公开信、宣传稿、简报
- **通知类**：会议通知、活动通知、工作通知

### 二、解题四步法

**第一步：审清题意——明确「写给谁」「干什么」**

审题是解题的第一步也是最重要的一步。务必明确：
- 发文机关：以什么身份撰写？（如某街道办、某部门负责人）
- 收文对象：写给谁看的？（领导、群众、同级部门）
- 行文目的：要达到什么效果？（部署工作、宣传教育、汇报情况）
- 字数要求：严格控制在要求范围内

**第二步：梳理材料——抓住「关键信息」**

贯彻执行题的答案来源主要是给定材料，因此必须高效梳理材料：
- 圈画数据信息：数据、时间、地点等具体信息
- 提取观点信息：材料中的观点、态度、建议
- 整合案例信息：典型的案例和做法
- 注意背景信息：问题背景、政策背景

**第三步：构建框架——定好「骨架」**

不同文种有不同的格式要求，但总体框架可以归纳为：

```
标题
↓
开头（背景/目的/依据）
↓
主体（分条分点，逻辑清晰）
↓
结尾（号召/要求/落款）
```

**第四步：填充内容——丰盈「血肉」**

在框架基础上，将材料中的关键信息加工整合后填入对应板块。注意语言的规范性和表达的准确性。

### 三、各类文种的高分模板

**（1）工作方案模板**

```
标题：关于[XX工作]的实施方案

开头：为贯彻落实[上级精神/政策要求]，切实解决[存在问题]，现制定如下方案：

一、指导思想
以[核心思想]为指导，坚持[基本原则]...

二、工作目标
（一）短期目标：...
（二）长期目标：...

三、主要任务
（一）[任务一]
（二）[任务二]
...

四、保障措施
（一）加强组织领导
（二）强化资金保障
（三）严格督查考核
```

**（2）讲话稿模板**

```
标题：在[XX会议/活动]上的讲话

各位[同志/同仁/代表]：

[开场白：点明会议背景和目的]

下面我讲几点意见：

一、充分认识[工作/问题]的重要性
...

二、准确把握[工作/问题]的着力点
...

三、切实加强[工作/问题]的组织推进
...

[结束语：号召、鼓励或总结]

谢谢大家！
```

**（3）倡议书模板**

```
标题：[关于XX的倡议书]

[称呼]：

[问题背景描述，引出倡议的必要性]

为此，我们向[对象]发出如下倡议：

一、做[XX]的[践行者/倡导者]
...

二、做[XX]的[传播者/守护者]
...

三、做[XX]的[推动者/示范者]
...

[号召性结尾：让我们携起手来...]

[落款]
[日期]
```

### 四、常见失分点和避坑指南

**格式扣分**
- 标题缺失或不当：一般文种必须有标题，标题要准确概括主题
- 称呼遗漏：讲话稿、倡议书等必须有称呼
- 落款不全：方案、通知等需要落款单位名称和日期

**内容扣分**
- 照搬材料：直接大段抄写材料原文，缺乏加工整合
- 脱离材料：凭空发挥，未充分利用材料信息
- 条理不清：没有分条分点，逻辑混乱
- 角色错位：以错误身份行文，如以部门名义写却用了上级口吻

**语言扣分**
- 口语化严重：公文写作需要用正式、规范的语言
- 空话套话：缺乏实质性内容，全是「高度重视」「狠抓落实」等空泛表述

### 五、日常积累建议

- **多读范文**：复习时多读历年的高分参考答案，学习格式和表达
- **关注时政**：多关注政府网站上的通知、方案、报告等，积累公文语感
- **动手练习**：每种文种至少练习5篇，形成肌肉记忆
- **仿写训练**：看到好的公文，可以仿照其结构和语言风格进行改写练习

贯彻执行题看似复杂，本质上是对考生公文写作能力和材料运用能力的考查。只要熟悉格式、掌握方法、勤加练习，这道「拦路虎」完全可以变成「送分题」。
