国考申论考试由注意事项、给定资料和作答要求三部分组成，其中第五题大作文占据**35-40分**（占总分近40%），是决定申论能否上线的关键。很多考生行测成绩不错，却因申论大作文拖后腿而与公务员擦肩而过。

## 一、国考申论大作文评分标准

### 评分等级划分

国考申论大作文一般采用「分类评分法」，将考生作文分为四类：

| 类别 | 分数段 | 评价标准 |
|------|--------|----------|
| 一类文 | 32-40分 | 立意准确，结构完整，论述深刻，语言流畅，字迹工整 |
| 二类文 | 24-31分 | 立意基本准确，结构较完整，论述较充分，语言较流畅 |
| 三类文 | 16-23分 | 立意有偏差，结构不完整，论述不充分，语言不通顺 |
| 四类文 | 0-15分 | 偏离题意，结构混乱，语言不通，或字数严重不足 |

### 评分维度详解

**1. 立意（10分）**

- 是否准确理解题意
- 中心论点是否明确
- 是否紧扣给定资料主题

**2. 内容（15分）**

- 论据是否充分有力
- 论述是否深入（不只罗列现象，有分析有对策）
- 是否结合实际（不空谈理论）

**3. 结构（8分）**

- 是否有清晰的开头、主体、结尾
- 段落之间是否有逻辑关联
- 是否采用「提出问题→分析问题→解决问题」的惯用结构

**4. 语言（5分）**

- 是否通顺流畅，无语病
- 是否有一定文采（适当引用名言、排比等）
- 是否使用规范书面语（避免口语化）

**5. 卷面（2分）**

- 字迹是否工整可辨
- 是否有涂改、错别字

## 二、国考申论大作文常见扣分点

### 扣分项一：立意偏离（扣5-15分）

**表现**：没有准确理解题意，中心论点偏离主题。

**示例**：题目是「新时代的奋斗者」，文章通篇写「努力的重要性」，未结合「新时代」特征。

**对策**：仔细审题，找出关键词，确保中心论点紧扣题目。

### 扣分项二：结构不完整（扣5-10分）

**表现**：缺少开头或结尾，或主体部分层次不清。

**对策**：采用标准结构：

```
开头（100-150字）：引出话题 + 提出中心论点
主体段1（200-250字）：分论点1 + 论据 + 分析
主体段2（200-250字）：分论点2 + 论据 + 分析
主体段3（可选，200字）：分论点3 + 论据 + 分析
结尾（100-150字）：总结全文 + 升华主题
```

### 扣分项三：论据不足（扣3-8分）

**表现**：只有论点，没有论据支撑；或论据与论点无关。

**对策**：每个分论点至少配1个论据（事例、数据、名言均可）。

### 扣分项四：语言口语化（扣2-5分）

**表现**：使用「我觉得」、「特别」等口语化表达。

**对策**：使用规范书面语，如「笔者认为」、「尤为重要」。

![考试学习](/images/lib/exam/e55_0.jpg)

### 扣分项五：字数不足（扣5-15分）

**规定字数**：一般要求1000-1200字。

**扣分标准**：
- 少50字以内：扣1-2分
- 少50-100字：扣3-5分
- 少100-200字：扣6-10分
- 少200字以上：归入四类文

**对策**：平时练习严格控制字数，考试时预留5分钟检查字数。

## 三、国考申论大作文高分技巧

### 技巧一：审题要「准」

花3-5分钟审题，找出题目中的**关键词**和**限定词**。

**示例题目**：「给定资料5」中提到，「实施乡村振兴战略，人才是关键」。请深入理解这句话，自选角度，自拟题目，写一篇文章。

**审题步骤**：
1. 关键词：乡村振兴、人才
2. 限定词：人才是关键（重点写人才的重要性、如何培养引进人才）
3. 自拟题目：如「筑牢乡村振兴的人才基石」

### 技巧二：开头要「快」

开头要在100-150字内完成「引出话题 + 提出中心论点」。

**模板**：
```
[引用/事例/背景]，这启示我们……。当前……[问题描述]。因此，……
[中心论点]。
```

**示例**：
```
浙江安吉余村的美丽蜕变，启示我们「绿水青山就是金山银山」。
当前，我国乡村发展仍面临人才流失、产业薄弱等挑战。因此，实施
乡村振兴战略，必须抓住「人才」这个关键。本文认为：筑牢乡村
振兴的人才基石，需要政策引才、平台育才、环境留才三管齐下。
```

### 技巧三：主体要「实」

每个主体段采用「分论点 + 阐释 + 论据 + 分析」四步法：

```
分论点：写好段首句，简洁明确。
阐释：用1-2句话解释分论点。
论据：使用事例/数据/名言。
分析：分析论据如何证明分论点（不要只罗列论据）。
```

**示例**：
```
政策引才是筑牢乡村振兴人才基石的「先手棋」。[阐释]中央和
地方出台了一系列引才政策，为乡村吸引人才提供了制度保障。
[论据]如「乡村振兴青春建功行动」实施以来，已累计选派33万余
名高校毕业生到基层任职。[分析]可见，有竞争力的政策是吸引
人才下沉乡村的关键。
```

### 技巧四：结尾要「升」

结尾要在总结全文的基础上**升华主题**，适当联系国家大政方针。

**模板**：
```
综上所述，……[总结分论点]。在……[时代背景]下，……
[升华主题，联系政策或愿景]。
```

**示例**：
```
综上所述，政策引才、平台育才、环境留才，是筑牢乡村振兴人才
基石的三大支柱。在全面建设社会主义现代化国家的新征程上，让更多
人才在乡村沃土上施展抱负、建功立业，乡村振兴的未来必将更加
美好。
```

## 四、国考申论大作文备考规划

### 阶段一：基础夯实（考前3-6个月）

- 每周精读2篇人民日报评论员文章，分析其立意、结构、论据
- 积累10-15个通用论据（人物事例、政策文件、数据）
- 练习审题和列提纲

### 阶段二：强化提升（考前1-3个月）

- 每周写1-2篇完整大作文，对照评分标准自评或互评
- 重点训练开头、结尾模板
- 积累主题类论据（如「高质量发展」、「共同富裕」、「基层治理」等）

### 阶段三：冲刺模拟（考前1个月）

- 严格按照考试时间（180分钟）完成整套申论试卷
- 大作文控制在50-60分钟内完成
- 重点检查立意是否准确、结构是否完整

## 五、常见大作文主题备考建议

根据近年国考申论主题，以下方向需重点准备：

| 主题方向 | 可能出现的题目关键词 |
|----------|----------------------|
| 高质量发展 | 创新驱动、产业升级、新质生产力 |
| 共同富裕 | 乡村振兴、区域协调、收入分配 |
| 生态文明建设 | 绿色发展、碳中和、绿水青山 |
| 基层治理 | 社区治理、网格化管理、枫桥经验 |
| 文化自信 | 传统文化传承、文化出海、精神文明建设 |

---

国考申论大作文高分的秘诀在于「准确立意 + 完整结构 + 充分论据 + 流畅语言」。建议考生从今天开始，每周至少完成1篇大作文写作练习，并对照评分标准反复修改，逐步形成自己的写作模板和论据库。
