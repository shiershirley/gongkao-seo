## 为什么数量关系让人头疼？

在国考行测五大模块中，数量关系是当之无愧的「得分洼地」。数据显示，每年国考行测中，数量关系的平均正确率仅为35%-45%，远低于言语理解（65%+）和判断推理（60%+）。

很多考生对数量关系的态度是「战略性放弃」——要么全选C，要么凭感觉蒙。然而，在竞争日益激烈的国考中，每0.1分都可能决定能否进面。掌握基本的速解技巧，在10道题中做对4-5道，就能有效拉开与竞争对手的差距。

![](/images/lib/office/office_v21_132.jpg)

本文不讲深奥的数学理论，只聚焦于国考行测数量关系中最实用的七种高频题型及其速解技巧，帮助你在有限的时间内拿到最多的分数。

## 一、数量关系模块速览

国考行测数量关系通常包含10-15道题（省部级15题、地市级10题），占总题量的8%-11%，参考作答时间建议10-15分钟。题型分布以基础应用题为主，纯数学推导题较少。

**近三年高频题型TOP7**：

| 题型 | 出现频率 | 难度 | 推荐得分目标 |
|------|---------|------|-------------|
| 工程问题 | 极高 | 中等 | 必拿 |
| 行程问题 | 高 | 中高 | 争取 |
| 经济利润问题 | 高 | 中低 | 必拿 |
| 容斥问题 | 高 | 低 | 必拿 |
| 排列组合 | 中高 | 中高 | 争取 |
| 几何问题 | 中 | 中等 | 争取 |
| 浓度问题 | 中低 | 中低 | 必拿 |

## 二、七大高频题型速解技巧

![](/images/lib/office/op7_1.jpg)

### 1. 工程问题：赋值法秒解

工程问题是数量关系中「送分题」的主力军，掌握赋值法可以在30秒内正确解答。

**核心思路**：将工作总量赋值为各工作时间的最小公倍数，快速求解效率。

**典型例题**：一项工程，甲单独做需要12天完成，乙单独做需要18天完成。两人合作需要多少天？

**速解步骤**：
1. 赋值工作总量 = 12和18的最小公倍数 = 36
2. 甲的效率 = 36÷12 = 3
3. 乙的效率 = 36÷18 = 2
4. 合作效率 = 3+2 = 5
5. 合作时间 = 36÷5 = 7.2天

整个解题过程不超过30秒，而常规设未知数列方程的方法至少需要2分钟。

**进阶技巧**：遇到「中间有人加入或离开」的变体题型，同样用赋值法。将工作分为不同阶段，分别计算各阶段的完成量，最后汇总。

### 2. 行程问题：画图+比例法

行程问题难度跨度大，简单题用基本公式即可，复杂题建议战略性跳过。

**核心公式**：路程 = 速度 × 时间（S=VT）

**速解技巧一：相遇追及画图法**

画一条线段表示全程，标注已知的速度和时间信息，直观看出等量关系。

**速解技巧二：比例转换法**

当路程相同时，速度与时间成反比。例如：从A到B，原速需要5小时，提速20%后需要多少小时？

解法：速度比 = 1:1.2 = 5:6，时间比 = 6:5，新时间 = 5×5/6 ≈ 4.17小时。

**判断是否该做的原则**：读完题目后10秒内能画出草图并明确思路的就做，否则果断跳过。不要在一道行程题上耗费超过2分钟。

### 3. 经济利润问题：公式套用+特值法

经济利润问题是理解成本最低、性价比最高的题型。核心就是几个简单公式：

**核心公式**：
- 利润 = 售价 - 成本
- 利润率 = 利润÷成本 × 100%
- 折扣后的售价 = 原价 × 折扣

**速解技巧：特值法**

当题目只给比例没有具体金额时，直接给成本赋值100元。

**典型例题**：一件商品按20%的利润率定价，再打9折销售，最终利润率是多少？

**速解步骤**：
1. 设成本 = 100元
2. 定价 = 100×(1+20%) = 120元
3. 售价 = 120×0.9 = 108元
4. 利润 = 108-100 = 8元
5. 利润率 = 8÷100 = 8%

全程一步到位，不需要设多元方程。

### 4. 容斥问题：公式+画圈法

容斥原理是数量关系中公式最固定、变化最少的题型。

**两集合公式**：A∪B = A + B - A∩B
**三集合公式**：A∪B∪C = A + B + C - (A∩B + B∩C + A∩C) + A∩B∩C

**速解技巧**：画三个相交的圆圈，把题目各项数据填入对应区域，未知数一目了然。

容斥问题的目标应该是「来一道、对一道」，因为它的解法几乎是标准化的。

### 5. 排列组合：分步分类法

排列组合让很多文科生考生头疼，但掌握了「分步用乘法、分类用加法」的核心原则，多数题目并不难。

**核心判断标准**：
- 分步（每一步都必须完成）：用乘法
- 分类（每一类都能独立完成）：用加法

**速解技巧**：
- 题目中有「依次」「逐个」等词 → 分步，乘法
- 题目中有「或者」「要么」等词 → 分类，加法
- 「至少一个」问题 → 用「全部情况 - 反面情况」转换

**排列（有序）vs 组合（无序）**：
- 选出后还要排序（如选班长和副班长）→ 用排列
- 选出即可不排序（如选3个人去开会）→ 用组合

排列组合建议做对中等难度及以下的题，遇到题干复杂、条件堆叠的题目果断跳过。

### 6. 几何问题：公式记忆+特殊值法

几何问题的核心是面积、体积公式的记忆。

**必记公式**：
- 圆面积：πr²； 圆周长：2πr
- 三角形面积：底×高÷2
- 勾股定理：a²+b²=c²（直角三角形）
- 相似三角形：对应边成比例

**速解技巧**：遇到求阴影面积的问题，通常用「大面积-小面积」的方法。遇到不规则图形，尝试割补法将其转化为规则图形的组合。

### 7. 浓度问题：十字交叉法

浓度问题是性价比最高的题型之一，用十字交叉法可以秒解大量混合浓度题。

**典型例题**：两种浓度分别为20%和50%的溶液混合成40%的溶液，两种溶液的质量比是多少？

**十字交叉法**：
```
   20%         10
        ↘    ↗
         40%
        ↗    ↘
   50%         20
```
质量比 = 10:20 = 1:2（低浓度:高浓度）

方法口诀：「大减小，对角线交叉，取绝对值」。

## 三、通用秒杀技巧

### 技巧一：代入排除法

当题目设问为「以下哪个选项……」或计算较为复杂时，直接将四个选项代入题目条件验证，往往比正向求解更快。

**适用场景**：
- 年龄问题
- 多位数问题
- 「最多/最少」问题

### 技巧二：整除特性法

利用数字的整除性质快速缩小答案范围。

**常用整除特性**：
- 末位能被2整除 → 该数是偶数
- 末两位能被4整除 → 该数能被4整除
- 各位数字之和能被3整除 → 该数能被3整除
- 各位数字之和能被9整除 → 该数能被9整除
- 末位是0或5 → 该数能被5整除

例如题目问「某数能被几整除」，直接观察选项的数字特征，排除不符合的选项。

### 技巧三：选项分析法

国考数量关系的选项设置往往有规律可循：

- 正确答案很少是选项中的最大或最小值（排除两个极端）
- 如果选项之间呈倍数关系，答案可能是中间值
- 如果某个选项与其他选项值差异很大，通常是干扰项

这些不是绝对的规律，但在时间紧迫时可以辅助判断。

## 四、考场时间分配策略

数量关系10道题，最佳策略是「先易后难」：

1. **快速浏览30秒**：扫一遍10道题，标注「简单题」（一看就有思路的）和「难题」（读完不知道在问什么的）
2. **先做简单题7-8分钟**：把标记为简单的题逐一解决，确保拿到基础分
3. **再做中等题3-4分钟**：尝试做有思路但不确定的题
4. **最后2分钟蒙题策略**：剩下的题统一蒙B或C（统计上这两个选项出现频率略高）

## 五、备考建议

**基础阶段（2-3周）**：系统学习七大题型的基本公式和解题思路，每天练20道题，保证每种题型都接触过。这个阶段重在「会做」，不追求速度。

**强化阶段（2-3周）**：大量刷真题，刻意练习速解技巧。每道题计时，目标是简单题1分钟内、中等题1.5分钟内完成。

**冲刺阶段（考前2周）**：模拟考场环境做套题，训练「先易后难」的做题节奏。考前一周回顾错题笔记。

国考从来不是选数学家，行测考的是思维方式和快速决策能力。数量关系不需要你每道题都会做，但需要你在最短的时间内拿到「属于你的分数」。希望每一位正在备考的考生都能突破数量关系的恐惧，多拿几分，距离上岸更近一步！
