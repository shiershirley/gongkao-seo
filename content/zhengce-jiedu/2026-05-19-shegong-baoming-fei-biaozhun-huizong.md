# 社区工作者考试报名费多少钱？各地收费标准及退费政策汇总

很多想报考社区工作者的朋友，在了解报名条件的同时，也关心报名费用问题。本文为大家整理各地社区工作者考试报名费标准及相关规定。

![](/images/lib/office/business_px.jpg)

## 一、社区工作者考试报名费全国概况

与国考、省考相比，社区工作者考试的报名费**相对较低**，部分地区甚至**免收报名费**。总体情况如下：

| 费用区间 | 地区特征 | 代表城市 |
|----------|----------|----------|
| 免费 | 部分省市全程免费 | 上海、广州部分区 |
| 50元以下 | 经济欠发达地区 | 部分西部省份 |
| 50-100元 | 大多数省市 | 北京、南京、杭州等 |
| 100-200元 | 一线及部分强二线 | 深圳、苏州等 |
| 200元以上 | 极少数地区 | 个别市辖区 |

**平均水平**：全国社区工作者考试报名费大约在**50-120元**之间，远低于公务员考试的费用。

## 二、主要城市报名费参考

### 上海

上海社区工作者（居委会工作人员）招聘通常由各区街道自行组织，部分区**不收取报名费**，或仅收取少量笔试/面试组织费。以近年数据参考：
- 浦东新区：免费
- 闵行区：免费
- 其他区：多数50元以内

### 北京

北京社区工作者考试由各街道组织，报名费标准：
- 笔试费：50-80元/人
- 面试费：视情况而定，部分不收取

### 广州

广州各区社区工作者考试：
- 笔试报名费：免费或30-60元
- 部分区明确免收考试费

### 深圳

深圳社区工作者（社康工作人员）：
- 笔试费：约50-100元
- 面试费：部分另收，约50元

### 杭州

- 报名费：50-80元
- 面试费：不额外收取

### 成都、重庆

- 报名费：40-60元左右

### 武汉、南京

- 报名费：60-100元左右

> **温馨提示**：以上数据仅供参考，实际以当年招聘公告为准。各地标准每年可能有所调整。

## 三、减免报名费政策

以下人群可能享受报名费减免政策：

### 1. 贫困户、低保家庭成员
多数地区对建档立卡贫困户、城乡低保家庭成员免收报名费，需提供相关证明材料。

### 2. 残疾人
部分地区对持有残疾证的报考者减免全部或部分报名费。

### 3. 应届高校毕业生
部分地区对应届毕业生在校期间申请减免的，可凭学生证、贫困证明等申请减免。

### 4. 下岗失业人员
部分地区对持有下岗证的失业人员减免报名费。

减免申请一般在网上报名时进行，需上传相关证明材料，经审核通过后自动减免。

## 四、缴费方式

目前主要缴费方式包括：

1. **网上支付**：微信支付、支付宝、银行卡支付——最常见
2. **银行转账**：汇款至指定账户，需保留转账凭证
3. **现场缴费**：部分地区要求到指定地点缴费
4. **无需缴费**：免费地区直接完成网上报名即可

## 五、退费政策

若报名后因各种原因无法参考，退费政策如下：

### 常见退费情形

| 情形 | 退费可能性 |
|------|------------|
| 报名审核未通过 | 全额退还 |
| 考试取消 | 全额退还 |
| 本人原因放弃 | 一般不退 |
| 报名成功后未参考 | 通常不退 |
| 特殊原因（不可抗力） | 视情况而定 |

### 退费注意事项

1. 报名审核未通过的，报名费一般在7-15个工作日内原路退还
2. 如遇考试整体取消（如因疫情等特殊情况），通常全额退还
3. 本人自愿放弃参考的，绝大多数地区不予退费
4. 退费申请须在规定时间内提出，逾期不受理

## 六、关于报名费的常见问题

**Q：报名费可以报销吗？**
A：如果是在职人员由单位推荐参加，部分单位可以报销；个人自愿报名的一般无法报销。

**Q：报名费能用对公账户转账吗？**
A：通常要求个人缴费，不接受对公转账。

**Q：缴费成功后没收到确认短信怎么办？**
A：登录报名系统查看缴费状态，或联系考试主办方确认。

**Q：网上支付失败但已扣款怎么处理？**
A：及时联系支付平台客服或银行，说明情况申请退款；同时联系考试主办方补录报名信息。

## 总结

社区工作者考试报名费整体偏低，全国大多数地区在50-120元之间，部分地区免费。特困、残疾等群体可申请减免。报名成功后未参考一般不退费，因审核未通过或考试取消则全额退还。建议关注当地最新招聘公告，以公告为准掌握确切收费标准和退费规则。
