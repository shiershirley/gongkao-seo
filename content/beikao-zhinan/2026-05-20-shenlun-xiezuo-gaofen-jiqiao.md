## 引言

申论，素有"玄学"之称，让无数考生感到头疼。与行测的"有标准答案"不同，申论需要考生具备阅读理解能力、综合分析能力和文字表达能力。如何在申论中取得高分？本文将为您详细解析五大题型的答题技巧。

## 一、申论题型分类总览

### 1.1 五大题型特点

| 题型 | 分值占比 | 难度 | 备考重点 |
|-----|---------|------|---------|
| 归纳概括题 | 20-25% | ★★☆☆☆ | 提取要点 |
| 提出对策题 | 20-25% | ★★★☆☆ | 问题+方案 |
| 综合分析题 | 20-25% | ★★★★☆ | 多角度分析 |
| 贯彻执行题 | 15-20% | ★★★☆☆ | 格式+内容 |
| 申发论述题 | 35-40% | ★★★★★ | 大作文 |

### 1.2 通用答题原则

1. **材料为王**：所有答案都要从材料中找
2. **问什么答什么**：不遗漏要点，不画蛇添足
3. **条理清晰**：分点作答，标清序号
4. **语言规范**：使用政府用语，避免大白话

## 二、归纳概括题技巧

### 2.1 题型特征

- 提问方式：概括、总结、归纳、简述
- 作答对象：问题、原因、措施、特点等
- 材料特点：以案例型材料为主

### 2.2 答题模板

**标准格式**：
```
1. 主体（企业/个人/政府）+ 做法 + 效果
2. ...
```

**高分技巧**：
- 每条答案控制在20字以内
- 使用动宾短语开头
- 相同类别的要点合并

**示例**：
> 问题：请概括材料中基层治理存在的问题
> 
> 答案：
> 1. 治理主体单一，群众参与不足
> 2. 数字化程度低，信息共享不畅
> 3. 部门协同不足，职能交叉推诿

## 三、提出对策题技巧

### 3.1 题型特征

- 提问方式：提出建议、解决措施、解决办法
- 作答对象：针对问题提出对策
- 材料特点：问题明确，对策需自己推导

### 3.2 答题模板

**标准格式**：
```
问题一：XXXX
对策一：XXXX
问题二：XXXX
对策二：XXXX
```

或：
```
对策一：从XXX角度，通过XXX措施，达到XXX效果
对策二：...
```

### 3.3 对策来源

| 来源 | 表述方式 |
|-----|---------|
| 材料直接给出 | 根据原文提炼 |
| 经验启示 | 从成功案例中学习 |
| 知识储备 | 常用对策手段 |
| 主观推导 | 根据问题反推 |

## 四、综合分析题技巧

### 4.1 题型特征

- 提问方式：谈谈理解、进行分析、评析
- 作答对象：观点、现象、问题
- 难度系数：最高，需要多角度思考

### 4.2 答题框架（以观点分析为例）

```
1.亮明观点：支持/反对/辩证看待
2.分析论证：
   (1) 合理性：材料论据+理论支撑
   (2) 局限性：可能存在的问题
3.总结提升：提出完善建议或启示
```

### 4.3 常见分析维度

| 维度 | 分析内容 |
|-----|---------|
| 政治维度 | 政策导向、政府作为 |
| 经济维度 | 成本效益、市场影响 |
| 社会维度 | 民生福祉、社会反响 |
| 文化维度 | 价值观念、文明程度 |
| 生态维度 | 环境保护、资源利用 |

## 五、贯彻执行题技巧

### 5.1 题型特征

- 提问方式：撰写XX文稿、起草XX
- 文种多样：通知、报告、倡议书、方案等
- 格式要求：标题+称谓+正文+落款

### 5.2 常见文种格式

#### 通知
```
【标题】
关于XXX的通知

各XXX：
一、...
二、...
三、...

XXX（单位）
XXXX年XX月XX日
```

#### 倡议书
```
【标题】
关于XXX的倡议书

广大XXX：
一、...
二、...
三、...

让我们XXX，共同XXX！

XXX（单位）
XXXX年XX月XX日
```

### 5.3 内容写作要点

1. **开头**：背景介绍，引出主题
2. **主体**：分条列项，内容充实
3. **结尾**：总结号召，呼应开头

## 六、申论大作文技巧

### 6.1 作文结构选择

**五段三分式（推荐）**：
```
开头：引出主题+亮明观点
分论点1：XX是XX的基础/关键/保障
分论点2：XX是XX的核心/重点/根本
分论点3：XX是XX的支撑/抓手/途径
结尾：总结升华+发出号召
```

### 6.2 开头写法

**公式**：问题/现象/名言 + 分析 + 亮明观点

**模板**：
> 当前，我国正处于社会转型的关键期，XX问题日益凸显。/ 俗话说，「民惟邦本，本固邦宁」。/ 十九大报告指出，...在此背景下，唯有XX，才能XX。

### 6.3 分论点展开

**每个分论点结构**：
```
分论点：XX是实现XX的关键一招
论据：材料中的案例 + 理论分析
论证：道理论证 + 举例论证
小结：因此/可见...
```

### 6.4 结尾写法

**公式**：回扣主题 + 总结全文 + 升华拔高

**模板**：
> 总之，「XX」不仅是实现XX的必然要求，更是推动XX的重要保障。/ 路虽远，行则将至；事虽难，做则必成。只要我们XX，就一定能XX。

## 七、评分标准深度解析

### 7.1 采分点分布

| 题号 | 分值 | 采分点数量 | 每点分值 |
|-----|------|-----------|---------|
| 第一题 | 20分 | 5-6个 | 3-4分/个 |
| 第二题 | 20分 | 5-6个 | 3-4分/个 |
| 第三题 | 20分 | 5-6个 | 3-4分/个 |
| 第四题 | 40分 | 多个维度 | 综合评定 |

### 7.2 加分项与扣分项

**加分项**：
- 语言规范，用词准确
- 逻辑清晰，层次分明
- 分析深刻，有独到见解
- 字迹工整，卷面整洁

**扣分项**：
- 脱离材料，泛泛而谈
- 要点遗漏，踩不到分
- 语言啰嗦，废话连篇
- 字迹潦草，难以辨认

## 八、备考建议

### 8.1 日常积累

1. **阅读政府文件**：人民日报、政府工作报告
2. **关注时政热点**：社会治理、民生改善等话题
3. **背诵优秀范文**：积累开头结尾模板
4. **练习规范表达**：将大白话转化为政府用语

### 8.2 做题技巧

1. **先看题目**：带着问题读材料
2. **标注关键词**：边读边标注重点
3. **分条列点**：每条控制在20字以内
4. **严格计时**：国考150分钟，省考120分钟

## 九、结语

申论备考的核心在于"以材料为王"，同时注重语言规范和逻辑清晰。建议考生：
1. 系统学习各题型答题框架
2. 每天坚持练习一道题
3. 定期进行全真模拟
4. 不断积累政府用语和规范表达

相信通过科学训练和持续积累，每位考生都能在申论中取得理想成绩！
