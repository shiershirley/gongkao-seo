## 在职备考者，你不是一个人在战斗

根据多项调查数据，公务员考试和事业单位考试的考生中，在职人员占比超过40%。他们白天要上班、晚上要学习，周末还要处理生活琐事。时间碎片化、精力不足、容易中断——这「三座大山」是在职备考者面前最大的障碍。

但与此同时，每年都有大量在职考生成功上岸。他们不是拥有更多时间，而是更懂得如何管理时间。![](/images/lib/exam/exam_v19_072.jpg)

本文将从时间规划、学习方法、精力管理三个维度，为在职备考者提供一套经过验证的高效复习方案。

## 一、在职工考的时间「家底」盘点

在规划复习之前，先客观评估自己实际可用的时间：

### 典型在职考生的一天

| 时段 | 时间 | 时长 | 可用性 |
|------|------|------|-------|
| 起床-出门 | 6:30-7:30 | 1小时 | ⭐⭐⭐ 可安排30分钟晨读 |
| 通勤 | 7:30-8:30 | 1小时 | ⭐⭐ 可听音频课程 |
| 上午工作 | 8:30-12:00 | 3.5小时 | ❌ 不可用 |
| 午休 | 12:00-13:30 | 1.5小时 | ⭐⭐⭐ 可安排30分钟刷题 |
| 下午工作 | 13:30-18:00 | 4.5小时 | ❌ 不可用 |
| 通勤 | 18:00-19:00 | 1小时 | ⭐⭐ 可听音频课程 |
| 晚餐+休息 | 19:00-20:00 | 1小时 | ⭐ 可看备考短视频 |
| 晚间学习 | 20:00-22:30 | 2.5小时 | ⭐⭐⭐⭐⭐ 黄金学习时间 |
| 睡前 | 22:30-23:00 | 30分钟 | ⭐ 可回顾当日学习 |

**每日可调配总时长**：约3.5-4小时（含碎片时间）
**每周可利用总时长**：工作日5天×3.5小时 + 周末2天×6小时 ≈ 29.5小时

30小时/周的时间，如果效率足够，对于一个有6个月备考周期的在职考生来说是完全够用的。关键在于——如何让这30小时产生最大价值。

## 二、碎片时间利用：让每一分钟都有产出

![](/images/lib/books/books_more_5.jpg)

在职备考最大的时间资源不是大块时间（因为很少），而是碎片时间。高效利用碎片时间，是在职考生拉开差距的关键。

### 通勤时间（日均2小时）

**最佳用途**：听课、听音频

- 乘坐公共交通：用手机APP看视频课程或听音频课程，通勤往返的2小时完全可以变成一节完整的课程时间
- 自驾：用蓝牙连接车载音响，听申论素材积累音频、时政热点解读音频
- 步行/骑行：听知识卡片类音频，每段3-5分钟，短小精悍

**推荐音频内容**：
- 时政热点（半月谈、人民日报评论）
- 常识判断知识点
- 言语理解成语辨析
- 申论规范表达和经典范文朗读

### 午休时间（可调配30分钟）

**最佳用途**：刷小题

利用午饭后30分钟集中刷一组题目，例如：
- 周一三五：行测模块练习（判断推理20题）
- 周二四：常识判断积累（20题+解析阅读）

不建议午休时间学习需要深度思考的内容（如数量关系难题、申论写作），因为大脑处于半休息状态，效率低下。

### 零散等待时间（排队、等餐等）

**最佳用途**：知识点速记

手机上安装备考APP或收藏备考小程序，利用随时随地可能出现的1-5分钟等待时间，快速浏览知识点卡片、回顾错题笔记。

## 三、晚间黄金2小时：高质量学习的核心

晚上20:00-22:00是在职考生最重要的学习时段。这2小时的质量直接决定了你的备考效果。

### 晚间学习三段式规划

| 时段 | 时长 | 内容 | 要求 |
|------|------|------|------|
| 20:00-20:50 | 50分钟 | 深度模块学习 | 关手机、不被打扰 |
| 20:50-21:00 | 10分钟 | 休息 | 起身走动、喝水 |
| 21:00-21:50 | 50分钟 | 刷题+对答案 | 计时做题、记录错题 |
| 21:50-22:00 | 10分钟 | 当日总结 | 记录学习内容和收获 |

**「关手机」是第一原则**。把手机放在另一个房间或设置为专注模式。晚上这2小时如果每隔5分钟看一眼手机，实际有效学习时间可能只有1小时。

### 模块轮换学习法

不要整个晚上只学一个科目，大脑会疲劳。建议采用「一主一副」搭配：

| 星期 | 主要内容（50分钟） | 辅助内容（50分钟） |
|------|------------------|------------------|
| 周一 | 言语理解 | 常识判断 |
| 周二 | 判断推理 | 时政热点 |
| 周三 | 数量关系 | 资料分析 |
| 周四 | 申论小题 | 言语刷题 |
| 周五 | 申论大作文 | 判断刷题 |
| 周六 | 全真模考（上午） | 错题整理（下午） |
| 周日 | 弱项突破 | 本周复盘+下周计划 |

## 四、周末：在职考生的「加速器」

周末两天是在职考生实现「弯道超车」的关键窗口。

### 周六计划（模考日）

| 时间 | 安排 |
|------|------|
| 9:00-11:00 | 行测全真模考（严格按考试时间） |
| 11:00-12:00 | 行测对答案、记录错题 |
| 14:00-17:00 | 申论全真模考（严格按考试时间） |
| 17:00-18:00 | 申论对照参考答案修改 |
| 20:00-21:30 | 总结当天的错题和薄弱点 |

**关键**：模考必须严格模拟真实考试环境——计时、不翻书、不查手机。多次在低压力环境下做对题，不等于在考场上能做对。

### 周日计划（复盘+突破日）

| 时间 | 安排 |
|------|------|
| 9:00-11:00 | 集中攻克本周发现的薄弱模块 |
| 11:00-12:00 | 知识框架梳理（画思维导图） |
| 14:00-16:00 | 申论素材积累+写作练笔 |
| 16:00-17:00 | 制定下周学习计划 |
| 17:00后 | 自由安排，适当放松 |

注意：周日晚上一定要给自己留出休息时间，避免出现「burnout」。弦绷得太紧反而容易断。

## 五、精力管理：比时间管理更重要

很多在职考生的问题不是「没时间」，而是「有时间但没精力」——下班回家累得不想动，翻开书就犯困。以下是几个实用的精力管理策略：

### 策略一：回家先「切换状态」

下班回家不要直接开始学习。用15-20分钟做一个「状态切换仪式」：洗个脸、换身衣服、喝杯茶、做几个拉伸动作。这个过程在大脑中建立一个「工作日结束，学习模式开启」的信号。

### 策略二：番茄工作法

以25分钟为一个「番茄」单位，专注学习25分钟后休息5分钟。每4个番茄休息15-30分钟。

研究表明，人的注意力持续时间是有限的。与其「硬撑」2小时低效学习，不如用4个高质量番茄+1个中等番茄，总共约2.5小时的高效产出。

### 策略三：运动保持精力

每周至少安排2-3次运动，每次30分钟以上。运动不仅增强体质，更重要的是促进大脑分泌多巴胺和内啡肽，改善情绪、提高专注力。

不需要去健身房。跳绳20分钟、下班后快走30分钟、周末打一场球，都是很好的选择。

### 策略四：提前1个月调整作息

考前1个月，将自己的作息调整到与考试时间同步。如果你习惯晚睡晚起，而考试是上午9点开始，那么你需要在考前1个月开始逐步提前入睡时间，确保考试当天在9点前大脑已经处于最佳状态。

## 六、在职备考「避坑」清单

### 坑一：贪多嚼不烂

买了10本教材、报了3个培训班、下载了无数资料——结果一本都没学透。在职备考最忌讳的是「资料囤积症」。

**正确做法**：选定一套主流教材和一个系统课程，学精学透。剩下的是「做减法」。

### 坑二：学习计划过于理想化

「每天学5小时」「周末学12小时」——这类计划一开始就注定失败。

**正确做法**：制定「最小可行计划」。工作日保底1.5小时（晚间集中），争取2.5小时（加碎片时间）；周末保底4小时/天。完不成最低目标要问责自己，超过了就给自己正反馈。

### 坑三：社交应酬不懂拒绝

「就吃一顿饭」「就唱一次歌」——每次应酬消耗的不只是时间，还包括第二天的精力。

**正确做法**：备考期间，把社交活动削减到最低。提前告知亲朋好友「我在备考，这段时间可能不能经常出来了」，真正理解你的人会支持你。

### 坑四：和别人比进度

在备考群里看到别人说「行测已经刷了5000题」「申论写了30篇」，而自己才刚起步，瞬间焦虑爆棚。

**正确做法**：屏蔽「晒进度」信息。每个人的基础不同、时间不同、目标不同。你只需要关注自己每天是否有进步。备考不是短跑，是马拉松。

## 七、写在最后

在职备考是一条不容易的路。白天应付工作已经筋疲力尽，晚上还要挑灯学习。没有人替你扛这份辛苦，但也没有人能夺走你应得的结果。

你今天的每一分付出，都是将来查成绩那一刻的底气。每天的2小时，6个月就是360小时。360小时的高效学习，足以让一个人从备考小白蜕变为笔试高手。

在职备考不丢人，丢人的是把「在职」当作不努力的借口。既然选择了考公这条路，就别给自己留退路。认准方向，咬紧牙关，6个月后的你，一定会感谢现在拼命的自己！
