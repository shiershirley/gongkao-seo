# 公考笔试时间分配与各模块答题顺序优化策略：行测提分的「隐形分数」

![备考资料](/images/lib/books/books_v23_112.jpg)

公考笔试中有一个扎心的事实：**绝大多数考生不是因为「不会做」丢分，而是因为「做不完」丢分**。

行测120分钟要做120—135道题，平均每题不到一分钟；申论150—180分钟要阅读近万字材料、写出两三千字的答案。在如此高压的时间限制下，比的已经不纯粹是知识储备，而是**时间管理能力**——谁能在有限时间内拿到更多的分，谁就能赢。

这就是为什么同样的知识水平，有的人能考75+，有的人只能考60出头——差距不在知识，在策略。

## 一、行测各模块的时间分配基准

行测五大模块（以国考副省级为例，共135题）：

| 模块 | 题量 | 建议用时 | 每题用时 | 目标正确率 |
|------|------|---------|---------|-----------|
| 常识判断 | 20题 | 8—10分钟 | 25—30秒 | 60%+ |
| 言语理解 | 40题 | 30—35分钟 | 45—50秒 | 80%+ |
| 数量关系 | 15题 | 10—15分钟 | 40—60秒 | 50%+ |
| 判断推理 | 40题 | 30—35分钟 | 45—50秒 | 80%+ |
| 资料分析 | 20题 | 20—25分钟 | 60—75秒 | 85%+ |
| **合计** | **135题** | **约108—120分钟** | | |

> 省考题量一般在120—130题，时间分配可按比例压缩。

### 各模块策略详解

**常识判断（保底分）**：会就是会，不会随便选。不要犹豫，平均每题不超过30秒。犹豫超过30秒也基本想不出来，纯属浪费时间。

**言语理解（基本盘）**：分值高、题量大，争取80%正确率。阅读理解类先看问题再看材料，逻辑填空先判断语义再做题。

**数量关系（抢分项）**：目标不是全做对，而是用10—15分钟做对6—8道最简单的。浏览全部题目，挑自己擅长的题型先做。不会的果断跳过，绝不恋战。

**判断推理（稳定输出）**：图形推理3—5分钟快速过（不会的跳过），逻辑判断要稳（宁可慢一点也要保证正确率）。

**资料分析（得分王）**：正确率最高的模块，要确保85%以上。先看题目再看图表，善用估算和速算，不要精确计算每一个数据。

## 二、三种个性化答题顺序方案

没有「万能顺序」，要根据自己的优势模块来定制。

### 方案A：资料分析前置型（推荐大多数考生）

```
资料分析（清醒时先拿下得分王）
→ 言语理解（保持状态）
→ 判断推理（逻辑活跃期）
→ 常识判断（快速过）
→ 数量关系（有余力就做）
```

**适用人群**：资料分析正确率较高的考生

**优势**：刚开考时头脑最清醒、注意力最集中，最适合做需要细心计算但不能太难的分析题。资料分析先做完，后面心态会稳定很多。

### 方案B：言语先行型（推荐文科背景）

```
言语理解（先热身）
→ 判断推理（渐入佳境）
→ 资料分析（顶峰期）
→ 常识判断（放松）
→ 数量关系（随缘）
```

**适用人群**：文科背景、数理偏弱的考生

**优势**：先从自己最擅长的言语和判断入手建立信心，资料分析在状态最好的时候做，数量关系放最后是因为投入产出比不高。

### 方案C：均衡稳定型（推荐各模块均衡的考生）

```
按试卷顺序做（常识→言语→数量→判断→资料）
但注意：数量关系中先挑简单题做，难题果断跳！
```

**优势**：不需要反复翻页，养成稳定节奏。

## 三、申论时间分配策略

申论考试通常150—180分钟（各省略有差异），时间相对行测充裕，但仍然需要合理分配：

| 题型 | 建议用时 | 操作要点 |
|------|---------|---------|
| 阅读材料 | 30—40分钟 | 第一遍速读（5分钟了解主题），第二遍精读并标注要点 |
| 归纳概括题 | 15—20分钟 | 快速找点+精简加工 |
| 综合分析题 | 20—25分钟 | 注意逻辑层次 |
| 提出对策题 | 20—25分钟 | 对策要具体可落地 |
| 大作文 | 50—60分钟 | 5分钟列提纲，35分钟写作，5—10分钟检查修改 |
| 检查时间 | 5—10分钟 | 核对要点、修改错别字 |

### 申论大作文时间分配（60分钟版）

| 环节 | 时间 | 产出 |
|------|------|------|
| 审题立意 | 5分钟 | 明确中心论点和分论点 |
| 列提纲 | 5分钟 | 五段式框架+每段关键词 |
| 写正文 | 35分钟 | 按提纲逐段填充 |
| 检查修改 | 10分钟 | 改错别字、调语句、补遗漏 |
| 缓冲 | 5分钟 | 应对意外情况 |

## 四、最容易被忽略的「隐形分数」——涂答题卡策略

每年都有考生因为涂答题卡时间不够而丢分。这分丢得最冤枉。

### 三种涂卡策略

| 策略 | 做法 | 优点 | 缺点 |
|------|------|------|------|
| 边做边涂 | 做5—10题就涂一次 | 不会最后来不及涂完 | 频繁切换思路影响节奏 |
| 模块涂卡 | 做完一个模块统一涂 | 节奏控制好，减少切换 | 如果某一模块超时，会连带 |
| 最后统一涂 | 全部做完再涂 | 专注做题时间最长 | **风险最大！不推荐！** |

### 推荐做法：模块涂卡法

每做完一个模块（约20—40题），花1—2分钟集中涂完该模块的答题卡。这样一举两得：
1. 不会出现最后没时间涂卡的悲剧
2. 涂卡间隙让大脑短暂休息，为下一模块蓄力

### 涂卡细节提醒
- 铅笔削成扁平状（比削尖更快涂满格）
- 准备2—3支削好的2B铅笔
- 涂完后快速扫一眼是否有漏涂
- 修改时务必擦干净，不要留痕迹

| 考前6天 | 专项突破弱势模块 | 错题整理 |

公考笔试是一场和时间赛跑的战斗。那些考完之后抱怨「题目不难但没做完」的考生，往往不是输给了知识，而是输给了策略。掌握科学的时间分配和答题顺序，至少能帮你多拿5—8分——而这5—8分，往往就是上岸和落榜的距离。
