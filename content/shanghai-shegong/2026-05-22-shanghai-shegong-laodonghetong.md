# 上海社区工作者劳动合同详解——聘用期限、续签条件与权益保障

在上海，社区工作者的用工形式是劳动合同制，这一点常常被外界误解。很多人以为社区工作者属于「编外临时工」或「政府雇员」，实际上社区工作者与街道办事处签订的是符合《劳动合同法》规定的正式劳动合同。那么这份合同的具体内容是什么？聘用期限多长？续签有哪些条件？本文为您详细解读。

![](/images/lib/city/city_v23_049.jpg)

## 一、社区工作者的用工性质

上海社区工作者实行「街聘街用」制度——由各街道办事处（或镇政府）作为用人单位，统一招聘、统一管理与社区工作者签订劳动合同。这一制度安排的法律依据是《中华人民共和国劳动合同法》和上海市相关实施办法。

核心要点：社区工作者是《劳动合同法》意义上的劳动者，享有法律赋予劳动者的全部权利，包括同工同酬、社会保险、带薪休假、劳动保护等。这与许多人以为的「临时工」「编外人员」有本质区别。

## 二、劳动合同的签订流程

一般来说，社区工作者在通过笔试、面试、体检、政审等全部招录环节后，由街道办事处通知签订劳动合同。具体流程如下：

1. **公示期结束**：拟录用人员名单公示（通常5-7个工作日）无异议后
2. **通知签约**：街道办事处发出录用通知书，告知签约时间和需携带材料
3. **合同签订**：双方当面签署劳动合同（一式三份），明确岗位、薪酬、期限等核心条款
4. **办理入职**：提交学历证书、体检报告、无犯罪记录证明等材料，办理社保登记和工资卡

## 三、劳动合同的关键条款

### 1. 聘用期限

上海社区工作者的劳动合同期限通常为**3年**（首次聘用），个别区采用「1+3」模式——即第一年为试用考察期，考核合格后续签3年固定期限合同。

| 合同类型 | 适用情况 | 期限 |
|---------|---------|------|
| 固定期限合同（首签） | 新入职社区工作者 | 通常3年 |
| 固定期限合同（续签） | 考核合格后续签 | 3年或5年 |
| 无固定期限合同 | 连续工作满10年或连续签订2次固定期限合同后 | 无固定期限 |

根据《劳动合同法》第十四条规定，连续订立二次固定期限劳动合同且劳动者没有法定解除情形的，续订劳动合同时应当订立无固定期限劳动合同。因此，在上海社区工作满6年以上且考核合格的社工，通常可以与街道签订无固定期限劳动合同。

### 2. 试用期

依据《劳动合同法》第十九条，劳动合同期限3年的，试用期不得超过6个月。上海社区工作者的一般做法是**试用期为3-6个月**，具体以各街道规定为准。

试用期内的工资待遇不得低于合同约定工资的80%，且不低于上海市最低工资标准。试用期满经考核合格者正式聘用，不合格者依法解除劳动合同。

### 3. 岗位与工作地点

劳动合同中会明确约定岗位名称（如社区服务站工作人员、网格管理员、社区事务受理员等）和工作地点（通常为街道下辖的某个社区）。因工作需要调整岗位或工作地点的，需双方协商一致。

### 4. 薪酬待遇

劳动合同中会明确薪酬构成，包括：
- 基本工资（按「三岗十八级」薪酬体系确定等级）
- 绩效工资（与年度考核结果挂钩）
- 津贴补贴（包括岗位津贴、交通补贴、通讯补贴等）
- 年终绩效奖金

## 四、续签条件与续签流程

合同到期前，街道办事处会对社区工作者进行聘期考核，考核结果是决定是否续签的主要依据。

**续签的必要条件**：
- 聘期内各年度考核均为合格及以上
- 无严重违反规章制度的行为
- 未达到法定退休年龄
- 个人自愿续签

**优先续签的情形**：
- 获得区级以上表彰或荣誉
- 持有中级及以上社工职业资格证书
- 在疫情防控、重大活动保障等工作中表现突出
- 居民满意度评价优秀

**通常不续签的情形**：
- 连续两年年度考核不合格
- 严重违反工作纪律或造成重大工作失误
- 因健康原因不能胜任岗位工作
- 个人主动提出不续签

## 五、合同解除（离职/辞退）

### 社区工作者主动离职

只需提前30日以书面形式通知用人单位即可解除劳动合同（试用期内提前3日通知）。街道办事处不得以任何理由阻挠或扣发工资。

### 用人单位解除合同

街道办事处在以下情形下可以解除劳动合同：
- 社区工作者严重违反规章制度
- 严重失职造成重大损害
- 以欺诈手段订立劳动合同
- 被依法追究刑事责任
- 不能胜任工作且经培训或调岗后仍不能胜任

需要特别注意的是，上海社区工作者享受「职业稳定保护」——街道办事处不得随意解除劳动合同。实际工作中，只要社区工作者认真履职、考核合格，工作稳定性非常强。

## 六、五险一金与其他权益保障

上海社区工作者依法享受以下社会保障：

| 保障项目 | 缴纳标准 | 说明 |
|---------|---------|------|
| 养老保险 | 单位16% + 个人8% | 企业职工基本养老保险 |
| 医疗保险 | 单位9.5% + 个人2% | 城镇职工基本医疗保险 |
| 失业保险 | 单位0.5% + 个人0.5% | 含失业金领取资格 |
| 工伤保险 | 单位0.2%-1.9% | 按行业风险等级 |
| 生育保险 | 已并入医疗保险 | 生育医疗费用和津贴 |
| 住房公积金 | 单位和个人各5%-7% | 各区标准略有差异 |

此外，社区工作者还享有以下权益：
- **带薪年休假**：工作满1年后每年5-15天（按工龄递增）
- **法定节假日**：依法享受11天法定节假日
- **加班待遇**：按规定支付加班工资或安排补休
- **工会福利**：参加街道工会，享受节日慰问、体检等福利
- **职业培训**：参加民政部门组织的各类专业培训

## 七、常见问题解答

**Q：社区工作者被辞退怎么办？**

A：如果认为辞退不合法，可以向劳动仲裁委员会申请仲裁。经济补偿金按工作年限计算——每满1年支付1个月工资。违法辞退需支付双倍赔偿金。

**Q：合同到期不续签有赔偿吗？**

A：除用人单位维持或提高条件而劳动者不同意续签外，合同到期不续签需要支付经济补偿金。

**Q：社区工作者的工龄能连续计算吗？**

A：在同一街道（镇）连续工作的，工龄连续计算。如果跨区调动，需与原单位协商办理社保关系转移。

## 八、总结

上海社区工作者的劳动合同制度已经相当成熟。作为法定劳动合同关系，社区工作者享有完整的劳动者权益保障，包括明确的薪资标准、完善的社会保险、稳定的续签机制和合法的离职保障。与大众印象不同，社区工作者并非「临时工」或「编外人员」，而是一个有法律保障、有职业前景的正规职业。

对于准备报考社区工作者的考生而言，了解劳动合同制度不仅是职场常识，也是面试中「岗位认知」类问题的必考内容。希望本文能帮助您建立对这一职业的全面认知。
