1. **`src/lib/content.ts`**：添加 `formatDate()` 函数，统一格式化为 `YYYY-MM-DD`
2. **24个文章文件**：给 date 字段加引号（`date: "2026-05-21"`）
3. **`scripts/frontmatter_validator.py`**：增加 date 未加引号检测规则
4. **`scripts/fix_date_quotes.py`**：新增批量修复脚本
