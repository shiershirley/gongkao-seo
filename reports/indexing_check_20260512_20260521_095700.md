## 四、优化建议

### 短期（本周内）

1. **注册 Bing Webmaster Tools**
   - 提交 sitemap：https://gk.edu-sjtu.cn/sitemap.xml
   - 申请抓取请求，加快新页面收录
   - 地址：https://www.bing.com/webmasters

2. **注册 Google Search Console**
   - 提交 sitemap 并查看 Google 收录状态
   - 地址：https://search.google.com/search-console

### 中期（本月内）

3. **提升文章内容质量**
   - 增加文章字数（建议 2000-3000 字）
   - 丰富 H2/H3 结构，增加内容深度
   - 避免重复模板化内容

4. **增加内部链接**
   - 在文章末尾添加相关推荐文章链接
   - 在同分类文章间建立链接关系

5. **百度收录主动推送**
   - 登录百度搜索资源平台，申请主动推送 API Token
   - 每次文章发布后自动推送到百度

### 长期

6. **建立外链策略**
   - 在相关社区/论坛适度分享文章
   - 与同类型网站建立友链

7. **定期监控收录趋势**
   - 每周一执行收录周报
   - 关注未收录文章的共同特征

## 五、百度收录查询方式

由于百度收录检查需要登录百度搜索资源平台，建议手动操作：

1. 访问 https://ziyuan.baidu.com
2. 登录账号
3. 进入「抓取收录」→「Sitemap」查看各URL状态
4. 或使用「链接提交」→「主动推送」功能批量提交
